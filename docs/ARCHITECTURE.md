# Архитектура

## Процессы и потоки

```text
Translater.exe (основной процесс, PySide6)
├─ поток Qt (UI)                окно, трей, оверлей, уведомления, опрос клавиш записи и рации (QTimer, 15 мс)
├─ поток горячих клавиш         RegisterHotKey + цикл сообщений Win32
├─ executor «inference» (1)     загрузка/выгрузка моделей и все запросы к процессу моделей, строго по одному
├─ поток «incoming»             очередь фраз → executor → субтитр
├─ поток «outgoing»             очередь записей → executor → текст → синтез SAPI → воспроизведение
├─ потоки захвата WASAPI        колбэки звука игры и микрофона
└─ разовые потоки               загрузка компонентов, прослушивание голоса

процесс моделей (multiprocessing spawn, inference/worker.py)
└─ faster-whisper на GPU, CTranslate2-перевод на CPU; RPC через Pipe
```

Процесс моделей запускается при загрузке первой модели и завершается после выгрузки последней. Только так CUDA
полностью освобождает видеопамять. Основной процесс не импортирует `ctranslate2` и `faster_whisper`.

Колбэки рабочих потоков попадают в UI только через сигналы `_Bridge` в `app.py`.

## Карта модулей

| Модуль | Ответственность |
|---|---|
| `app.py` | Точка сборки: создаёт всё, связывает Qt и рабочие потоки, загрузка компонентов, мьютекс единственного экземпляра, `QLocalServer` для активации окна. |
| `config.py` | `AppConfig`: JSON-формат, значения по умолчанию, диапазоны, `validate`, поэлементное чтение с откатом на значения по умолчанию, пути данных. |
| `controller.py` | `ModeController`: состояния режима `IDLE → LOADING → ACTIVE`, запуск и остановка `ModeRunner`. |
| `models.py` | `ModelManager`: счётчик ссылок на модели, загрузка через executor, выгрузка по таймеру. |
| `components.py` | Закреплённые компоненты (URL, SHA-256, размер), `ComponentStore`: загрузка с докачкой и проверкой. |
| `inference/process.py` | `InferenceProcess`: запуск процесса моделей, RPC, перезапуск после падения, `WorkerError`. |
| `inference/worker.py` | Сам процесс моделей: обработчики `load`, `unload`, `incoming`, `outgoing`, `probe`. |
| `inference/speech.py` | `SpeechRecognizer` (Whisper, один проход кодировщика), `TextTranslator` (quickmt). |
| `inference/filters.py` | Отсев галлюцинаций Whisper, ограничение длины перевода, свёртка повторов. |
| `incoming.py` | `IncomingRunner`: звук → фразы → процесс моделей → субтитры; буфер последних 60 с. |
| `outgoing.py` | `OutgoingRunner`: запись по клавише → процесс моделей → синтез → воспроизведение по рации. |
| `audio/capture.py` | WASAPI: захват звука процесса игры, loopback устройства, микрофон. |
| `audio/vad.py`, `audio/segmenter.py` | Silero VAD (onnxruntime) и нарезка потока на фразы. |
| `audio/resample.py`, `audio/playback.py`, `audio/wav.py` | Ресемплинг (PyAV), вывод на устройство, WAV для диагностики. |
| `tts.py` | Английские голоса Windows (SAPI и OneCore) через pywin32. |
| `win32/` | `RegisterHotKey`, `GetAsyncKeyState`, мьютекс, приоритет, список окон процессов. |
| `ui/` | Главное окно, форма настроек, захват клавиш, трей, оверлей субтитров, окно чата (`chat.py`), уведомление, тема. |
| `doctor.py` | `python -m translater.doctor`: отчёт об окружении. |
| `selftest.py` | `Translater.exe --self-test <отчёт>`: проверка упаковки в CI. |

## Жизненный цикл режима

1. Горячая клавиша или кнопка → `_Application._toggle`.
2. Если для режима не хватает компонентов (`MODE_COMPONENTS`), программа проверяет свободное место, спрашивает
   пользователя и скачивает их в отдельном потоке.
3. `ModeController.activate` → `ModelManager.acquire(MODE_MODELS[mode])`: модели загружаются через executor, состояние —
   `LOADING`.
4. После загрузки запускается runner режима, состояние — `ACTIVE`.
5. `deactivate` останавливает runner вне блокировки контроллера и освобождает модели. Если на модель нет других ссылок,
   через `unload_delay_s` она выгружается. Когда выгружена последняя модель, завершается процесс моделей.

## Входящий конвейер

```text
GameAudioSource (захват процесса игры, иначе loopback устройства)
  → MonoResampler (16 кГц, моно)
  → SpeechSegmenter + SileroVad (порог из настроек, пауза 0,5 с, фраза ≤ 12 с)
  → очередь (≤ 3 фраз, старше 8 с — пропуск)
  → executor → worker «incoming»:
       Whisper: кодирование одним проходом → выбор языка en/ru → декодирование (beam 2 или 5)
       en → перевод quickmt en→ru; ru → как есть
  → _Bridge → SubtitleOverlay (если включены субтитры) и ChatWindow (история, 500 фраз в памяти)
```

Пока режим включён, последние 60 с звука хранятся в памяти (до следующего включения режима), а уровень звука пишется
в журнал раз в 10 с. Сочетание `save_audio`, кнопка в окне и пункт трея сохраняют этот буфер в WAV.

Глобальные сочетания перечислены в `GLOBAL_HOTKEYS` (`config.py`). Их действия — в `_Application._hotkey_actions`.

## Исходящий конвейер

```text
клавиша записи нажата (опрос GetAsyncKeyState) → MicrophoneSource, предзапись 0,3 с
клавиша отпущена → запись ≥ 0,4 с → executor → worker «outgoing»:
       Whisper (только ru) → перевод quickmt ru→en
  → текст в оверлей, окно чата и буфер обмена → синтез SAPI → сигнал в наушники
клавиша рации нажата → DevicePlayer «CABLE Input» + копия в наушники с громкостью monitor_volume
клавиша рации отпущена → воспроизведение остановлено, фраза ждёт следующего нажатия
```

Объект SAPI создаётся и используется только в потоке «outgoing».

## Принятые решения

- **Python 3.14 и PySide6.** Окно, трей и оверлей сделаны на одном фреймворке. Поддерживаются Python 3.12–3.14: для
  более новых версий нет сборок ctranslate2 и onnxruntime.
- **Захват звука игры.** Используется WASAPI process loopback по примеру Microsoft ApplicationLoopback (comtypes).
  Запасной вариант — loopback устройства вывода через PyAudioWPatch. У активации и остановки есть таймауты.
- **Распознавание.** faster-whisper на GPU (`int8_float16`). Фраза кодируется один раз, и этот результат используется
  и для выбора языка, и для распознавания (см. `SpeechRecognizer`).
- **Перевод.** CTranslate2 и SentencePiece на CPU (`int8`), quickmt. Против зацикливания: `no_repeat_ngram_size`,
  `repetition_penalty`, ограничение длины, свёртка повторов.
- **Отдельный процесс для моделей.** Так видеопамять освобождается полностью, а падение CUDA не роняет интерфейс.
- **Один поток для GPU.** Загрузка, выгрузка и инференс идут последовательно, без гонок за видеопамять.
- **Сочетания вкл/выкл.** Используется Win32 `RegisterHotKey` с модификатором, игра эти сочетания не получает.
- **Клавиши записи и рации.** Их нажатие проверяется опросом `GetAsyncKeyState` и только во включённом исходящем
  режиме. Ввод не перехватывается: клавиша доходит до игры без задержки. Программа не нажимает клавиши в игре и не
  внедряется в её процесс.
- **Компоненты.** Скачиваются при первом включении режима, а не входят в архив: архив остаётся небольшим.
  Версии закреплены по коммиту и SHA-256.
- **Пониженный приоритет.** Основной процесс работает с приоритетом ниже обычного, чтобы не отнимать время у игры.
- **PyInstaller `--onedir`.** Запускается быстрее и реже вызывает ложные срабатывания антивирусов, чем один файл.
