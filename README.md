# Translater

Локальный переводчик голосового чата для игр (Windows). Без облака.

- **Входящий перевод** (вкл/выкл по сочетанию): речь игроков → субтитры на русском поверх игры.
- **Исходящий перевод** (вкл/выкл по сочетанию): пока удерживаете клавишу записи, программа записывает русскую речь,
  переводит её на английский и озвучивает в виртуальный микрофон (VB-Cable). В игру озвучка уходит по вашей клавише рации.

В простое программа держит только окно или значок в трее и горячие клавиши: моделей в памяти нет, аудиопотоки закрыты.

## Состояние

| Этап | Что | Статус |
|---|---|---|
| 0 | Проверка окружения (`python -m translater.doctor`) | готово |
| 1 | Окно, трей, настройки клавиш, горячие клавиши, жизненный цикл моделей, сборка .exe | готово, ждёт проверки в Windows |
| 2 | Входящий режим: захват звука игры, VAD, распознавание, перевод, субтитры | — |
| 3 | Исходящий режим: запись по клавише, распознавание, перевод, текст | — |
| 4 | Озвучка в VB-Cable | — |
| 5 | Оптимизация и замеры | — |

## Установка

1. Откройте страницу [Releases](https://github.com/EXTRBXY/translater/releases) и скачайте последний
   `Translater-<версия>-win-x64.zip`.
2. Распакуйте архив в любую папку, например `D:\Translater`.
3. Запустите `Translater.exe`. Ярлык на рабочий стол — правый щелчок по файлу → «Отправить» → «Рабочий стол».

Программа не подписана сертификатом, поэтому Windows SmartScreen при первом запуске может показать «Система Windows
защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».

Обновление: закройте программу (значок в трее → «Выход»), распакуйте новый архив поверх старой папки. Настройки
хранятся отдельно и сохраняются.

## Использование

Главное окно показывает оба режима, их сочетания и кнопки «Включить»/«Выключить». Там же настраиваются клавиши.
Закрытие окна сворачивает программу в трей, горячие клавиши продолжают работать. Открыть окно снова — щелчок по
значку в трее или повторный запуск `Translater.exe`. Выход — значок в трее → «Выход».

Цвет значка: серый — выключено, жёлтый — загрузка, зелёный — режим включён, красный — идёт запись.

Настройки — `%APPDATA%\Translater\config.json`, журнал — `%LOCALAPPDATA%\Translater\logs\translater.log`
(тексты фраз и звук не записываются).

## Разработка (Python 3.14)

```powershell
py -3.14 -m venv .venv
.venv\Scripts\pip install -e .[dev]
.venv\Scripts\python -m pytest
.venv\Scripts\python -m translater.doctor   # отчёт об окружении
.venv\Scripts\python -m translater
```

Релиз: поднять `version` в `pyproject.toml`, закоммитить, отправить тег `vX.Y.Z` с той же версией. GitHub Actions
(`.github/workflows/release.yml`) прогонит тесты, соберёт `Translater.exe` через PyInstaller и опубликует архив в
Releases.

## Настройка звука для исходящего перевода (этап 4)

1. Установить VB-Cable с официального сайта vb-audio.com.
2. Windows → Звук → Запись → ваш микрофон → Свойства → Прослушать → «Прослушивать с данного устройства»,
   устройство воспроизведения — `CABLE Input`.
3. В игре устройство ввода — `CABLE Output`.

Обычная речь идёт в игру как раньше, по клавише рации. Перевод: удерживаете клавишу записи и говорите (рацию не
нажимаете), после сигнала зажимаете рацию — программа проигрывает озвучку.

## Принятые решения

- Python 3.14 (поддерживается 3.12–3.14: для более новых нет сборок ctranslate2 и onnxruntime) + PySide6: окно, трей и оверлей на одном фреймворке.
- Сборка — PyInstaller в режиме папки (`--onedir`): быстрее запуск и меньше ложных срабатываний антивирусов, чем у одного файла.
- Сочетания вкл/выкл — Win32 `RegisterHotKey` с модификатором; игра эти сочетания не получает.
- Клавиша записи — опрос `GetAsyncKeyState` раз в 15 мс только во включённом исходящем режиме. Без перехвата ввода:
  клавиша доходит до игры, задержки ввода нет. Поддерживаются клавиши и средняя/боковые кнопки мыши.
- Загрузка, выгрузка моделей и вся работа на GPU — в одном потоке, строго по одной задаче.
- Программа не нажимает клавиши в игре и не внедряется в её процесс.
